# Munshi Rifat — Personal Portfolio

A responsive dark navy and blue personal portfolio built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages.

## Files

- `index.html` — website content
- `style.css` — layout, colors, typography, and responsive design
- `script.js` — mobile navigation and current year
- `assets/profile.svg` — temporary portrait placeholder

## Before publishing

1. Replace `assets/profile.svg` with your own photo. Easiest: add your image as `assets/profile.jpg`, then in `index.html` change:
   ```html
   <img src="assets/profile.svg"
   ```
   to:
   ```html
   <img src="assets/profile.jpg"
   ```
2. Replace the YouTube placeholder link (`https://www.youtube.com/`) with your channel URL.
3. Replace `your.email@example.com` with your real email.
4. In the Projects section, replace GitHub profile links with the exact repositories once your projects are uploaded.
5. Check all claims and skill levels so they accurately reflect what you have learned.

## Publish with GitHub Pages

For a clean personal site URL, create a **public repository named exactly**:

`munsirifatm.github.io`

Then upload the contents of this folder to the repository root (make sure `index.html` is at the root). On GitHub, open **Settings → Pages** and choose publishing from the `main` branch and `/ (root)`. Save, then wait for GitHub Pages to publish.

The expected URL is:

`https://munsirifatm.github.io/`

GitHub Pages hosts static sites; this project does not need PHP or a database.

## Local preview

Open `index.html` in a browser. For best results, use a local development server or VS Code Live Server.
